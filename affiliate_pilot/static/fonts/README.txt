Figtree Regular (400) and Bold (700)

These TrueType files were generated from the repository's existing
app/static/figtree-latin.woff2 by instantiating the corresponding weight and
changing the container from WOFF2 to TrueType. They include Portuguese accented
letters, the ellipsis and bullet used in affiliate cards.

Original project: https://github.com/erikdkennedy/figtree
License: SIL Open Font License 1.1, reproduced in Figtree-OFL.txt.

The card renderer loads these bundled files directly. No font download, system
font package, FontTools or Brotli dependency is needed at runtime.
