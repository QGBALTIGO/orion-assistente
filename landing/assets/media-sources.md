## Preparação e uso

As fotos foram convertidas para WebP com largura de 1600 pixels, preservando a proporção. Não houve recorte, retoque, geração de conteúdo ou alteração de cor. O layout define o enquadramento por CSS. Metadados embutidos foram removidos dos arquivos de entrega.

O vídeo deve ser iniciado pelo visitante, com controles, `playsinline` e `preload="none"`. Não é uma demonstração do software. Uma demonstração do Orion deve usar sua interface e dados fictícios claramente identificados.
