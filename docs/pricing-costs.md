# Modelo de preço e custos — hipóteses, não cotações oficiais

**Receita recorrente mensal:** N clientes ativos × ticket médio pago.

**Custo mensal estimado:** servidor compartilhado + backups externos +
domínio + mensagens WhatsApp por categoria e quantidade + eventuais
tokens de IA + gateway de pagamentos + monitoramento + suporte +
impostos + taxas e despesas de aquisição.

**Margem de contribuição por tenant:** receita paga pelo tenant − custos
variáveis diretamente atribuíveis (mensagens, IA, taxa de pagamento,
horas de suporte, etc.). Custos fixos rateados são medidos separadamente.

Valores R$ 59,90 / R$ 79,90 / R$ 89,90 são **cenários ilustrativos** do
documento mestre, não preços aprovados para venda nem margens prometidas.

na data de contratação para obter tarifas vigentes.
